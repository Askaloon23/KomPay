# Лабораторная работа №4 — «Коммуналка»

Консольное Python-приложение с архитектурой: UI → сервисы → репозитории → SQLite.

## Запуск в Visual Studio Code
1. Откройте папку `lr4_kommunalka` в VS Code.
2. Установите Python 3.10 или новее.
3. Откройте терминал VS Code и выполните `python main.py` (в Windows также можно `py main.py`).
4. При первом запуске автоматически создаётся `database/kommunalka.db` и справочники.

Сторонние библиотеки не требуются.

## Важно о предоставленной базе `.odb`
Файл `Kommunalka osnova.odb` — это встроенная база HSQLDB, а не SQLite. Модуль `sqlite3` не может открыть её напрямую. В методичке приведён пример SQLite, поэтому приложение реализовано на SQLite с той же структурой из семи таблиц и связями. Существующие записи из `.odb` автоматически не переносятся; исходный файл не изменяется. Для переноса данных экспортируйте таблицы из LibreOffice Base в CSV и импортируйте их в соответствующие таблицы SQLite, сохраняя ID и порядок внешних ключей.

Справочники при первом запуске заполняются демонстрационными названиями, так как текстовые значения справочников исходной базы не были надёжно извлечены из файла. Их можно заменить в меню справочников.

## Слои
- `models/entities.py` — семь моделей `dataclass`.
- `repositories/` — универсальные CRUD-операции с параметризованными SQL-запросами.
- `services/` — проверки, начисления, платежи, квитанции, авторизация.
- `ui/console.py` — консольная навигация и ролевые меню.
- `database/` — подключение и создание схемы.

Пароли новых пользователей хранятся в виде SHA-256-хеша. Для совместимости предусмотрен вход в старые записи с открытым паролем и его обновление до хеша после успешного входа. Для реальной эксплуатации следует использовать более стойкий алгоритм хранения паролей (например, Argon2/bcrypt).
