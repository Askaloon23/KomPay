# KomPaY

## О проектe

KomPaY — приложение для учёта коммунальных услуг и связанных с ними начислений.

Система предназначена для хранения информации о потребителях и объектах недвижимости, учёта показаний приборов, расчёта стоимости коммунальных услуг и контроля начислений.

Программа позволяет автоматизировать основные операции, связанные с ведением коммунального учёта, сократить количество ручных расчётов и обеспечить удобный доступ к информации о начислениях и оплатах.

## Принцип работы системы 

Программа построена по трёхуровневой архитектуре:

**Слой пользовательского интерфейса** — обеспечивает взаимодействие пользователя с программой.<br>
**Слой бизнес-логики** — выполняет проверку введённых данных, расчёты потребления и стоимости коммунальных услуг, а также обработку основных операций системы.<br>
**Слой данных** — отвечает за хранение информации о пользователях, объектах недвижимости, коммунальных услугах, тарифах, показаниях приборов и начислениях.

## Основные возможности

В системе предусмотрены следующие возможности:

• регистрация и авторизация пользователей;<br>
• ведение информации о жилых объектах;<br>
• хранение данных о потребителях;<br>
• добавление и редактирование коммунальных услуг;<br>
• учёт тарифов на коммунальные услуги;<br>
• ввод показаний приборов учёта;<br>
• расчёт потребления коммунальных ресурсов;<br>
• автоматический расчёт стоимости услуг;<br>
• просмотр начислений;<br>
• просмотр истории показаний;<br>
• просмотр информации об оплатах;<br>
• формирование и просмотр данных по коммунальным услугам.<br>

## Запуск проекта

**1. Клонирование репозитория**
```
git clone <URL-репозитория-KomPaY><br>
```
**2. Переход в каталог проекта**
```
cd KomPaY
```
**3. Создание виртуального окружения**

**Windows:**
```
python -m venv venv
```
**Linux/macOS:**
```
python3 -m venv venv
```
**4. Активация виртуального окружения**

**Windows:**
```
venv\Scripts\activate<br>
```
**Linux/macOS:**
```
source venv/bin/activate<br>
```
**5. Установка зависимостей**
```
pip install -r requirements.txt<br>
```
**6. Запуск программы**

**Windows:**
```
python src/kompAY/main.py
```
**Linux/macOS:**
```
python3 src/kompAY/main.py
```
После запуска пользователю будет доступно основное меню программы KomPaY.

Для проверки работоспособности программы предусмотрены автоматизированные модульные тесты.

Для запуска тестов выполните:

**Windows:**
```
python -m unittest discover -s tests
```
**Linux/macOS:**
```
python3 -m unittest discover -s tests
```
