KomPay
О проекте
KomPay — учебное консольное приложение для оплаты коммунальных услуг.
Программа позволяет пользователю зарегистрироваться, войти в систему, добавить лицевой счёт, оплачивать коммунальные услуги и просматривать историю платежей.
Основные возможности
Пользователь
• регистрация;
• авторизация;
• добавление лицевого счёта;
• просмотр лицевых счетов;
• оплата коммунальных услуг;
• просмотр истории платежей.
Администратор
В дальнейшем планируется добавить:
• просмотр пользователей;
• просмотр всех платежей;
• управление коммунальными услугами;
• просмотр статистики.

Запуск
Клонировать репозиторий:
git clone https://github.com/USERNAME/KomPay.git
cd KomPay
Запустить программу:
python -m src.komp_pay.main
Тестирование
Запустить тесты:
python -m unittest discover
