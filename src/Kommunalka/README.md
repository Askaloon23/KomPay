# Система управления ЖКХ (Коммуналка)

Учебный проект — многослойное консольное приложение.

## Структура

- `database/` — подключение и инициализация БД
- `models/` — модели данных (dataclass)
- `repositories/` — слой доступа к данным (CRUD)
- `services/` — бизнес-логика
- `ui/` — консольный интерфейс

## Запуск

```bash
python main.py
```

## Учётные записи по умолчанию

| Роль          | Логин | Пароль |
|---------------|-------|--------|
| Администратор | admin | admin  |
| Бухгалтер     | buh   | buh    |

## Возможности

### Администратор
- Просмотр пользователей, услуг, начислений, платежей
- Создание бухгалтеров и администраторов

### Бухгалтер
- Просмотр данных
- Создание начислений
- Регистрация платежей
- Выдача квитанций

### Жилец
- Просмотр своих начислений и платежей
- Просмотр тарифов
